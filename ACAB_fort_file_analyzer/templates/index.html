ACAB Fort File Analyzer

Herramienta de análisis de isótopos para simulaciones ACAB.
Carga los ficheros fort.6 e inp.5 de múltiples simulaciones
y visualiza la actividad, tablas comparativas e informe detallado del isótopo seleccionado.

Cómo usar:
  1. Introduce la ruta de la carpeta que contiene las subcarpetas de simulaciones.
  2. Cada subcarpeta debe contener al menos un fichero fort.6.
  3. Para leer Tirr, Tcool y flujo automáticamente, incluye inp.5 en cada subcarpeta.
  4. Opcionalmente, sube un fichero YAML de configuración de semividas y figuras.
  5. Haz clic en Analizar.
Estructura esperada:
carpeta_padre/
  simulacion_A/fort.6  [inp.5]
  simulacion_B/fort.6  [inp.5]
  …
  [figuras.yaml]
