Cada “set” = Block #7 (control, 8 parámetros) + Block #8 (hasta 10 tiempos finales). El reloj se reinicia a 0 al final de cada período de irradiación. Se recomienda escala ×2 en irradiación y ×3 en enfriamiento.

MSUBPaso del set anterior usado como punto de partida (relevante cuando NOPUL ≠ 0).
IUNITUnidades de tiempo: 1=s, 2=min, 3=h, 4=días, 5=años, 7=10³ a, 8=10⁶ a, 9=10⁹ a.
